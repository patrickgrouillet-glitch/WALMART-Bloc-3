## Data

Walmart_Store_sales.csv

## Descriptif du projet
L'entreprise WALMART est une multinationale américaine qui exploite une chaîne d'hypermarchés

Le service marketing a besoin d'un modèle d'apprentissage automatique capable d'estimer les ventes hebdomadaires dans leurs magasins en fonction de l'incidence de certains indicateurs économiques

## Etude statistique
Il faut pour cela :
      - réaliser une analyse exploratoire
      - entrainer un modèle de régression linéaire
      - éviter le surapprentissage grâce à un modèle de régression régularisé

## Présentation
      - convertir les dates dans un format "date" permettant les calculs
      - convertir les températures données en degrés Fahrenheit en degrés Celsius
      - créer des visualisations sur les données descriptives
      - éliminer les "outliers"
      - établir un modèle de régression linéaire sur set d'entrainement
      - tester ce modèle sur le set de test
      - contrôler l'éventuel surapprentissage
      - mesurer par des coefficients l'incidence de chaque valeur sur le niveau des ventes
      - tester plusieurs valeurs d'alpha en régularisation L1 LASSO et L2 RIDGE pour éviter surapprentissage
      - comparer les meilleurs résultats de ces deux méthodes
